# 개발 계획서 (2026-11-17 23:30)

## 1. 개요
교회 강단 예약시스템(Booking Web App)의 기본 서브패스(`/reserve`)를 환경변수 `DEFAULT_PREFIX`를 통해 동적으로 설정 및 변경할 수 있도록 애플리케이션 라우팅 구조와 `Dockerfile` 설정을 개선합니다. 또한 프로젝트 요구사항/계획/이력/결과 문서화 체계를 `notes/` 디렉토리에 구축하고 `README.md`를 최신화합니다.

## 2. 세부 작업 계획

### Step 1: 요구사항 및 계획 문서화 (`notes/`)
- `notes/plan_202611172330.md`: 본 개발 계획 수립 및 기록
- `notes/req_202611172330.md`: 사용자 원본 요구사항 및 계획 통합 기록
- `notes/requirement.md`: 누적 요구사항 기록

### Step 2: `DEFAULT_PREFIX` 환경변수 연동 코드 수정 (`app.py`, `main.py`, `.env`)
- `.env` 로드 시 기존 시스템/컨테이너 환경변수를 덮어쓰지 않도록 `os.environ.setdefault` 적용 및 `.env`에 기본 `DEFAULT_PREFIX=/reserve` 명시
- `normalize_prefix()` 헬퍼 함수를 구현하여 `DEFAULT_PREFIX` 값 정규화:
  - 미설정 시 기본값 `/reserve` 적용
  - 앞쪽 슬래시(`/`) 보장 및 뒤쪽 슬래시 제거 (단, 빈 문자열 `""` 또는 `"/"` 지정 시 루트 경로 `""`로 동작)
- Flask 앱 및 Blueprint(`reserve_bp`)의 `url_prefix`와 정적 파일 경로(`static_url_path`)가 `DEFAULT_PREFIX`를 참조하도록 수정
- 헬스체크 엔드포인트(`{DEFAULT_PREFIX}/api/status` 및 `/api/status`) 연동
- 루트(`/`) 접속 시 `DEFAULT_PREFIX` 메인 화면(`reserve.index`)으로 안전하게 리다이렉트되도록 처리
- `main.py`를 Gunicorn 진입점(`main:app`)으로 사용할 수 있도록 구성 유지 및 정비

### Step 3: `Dockerfile` 수정
- `ENV DEFAULT_PREFIX=/reserve` 환경변수 기본값 선언 추가
- 요청 사양에 맞춘 컨테이너 `HEALTHCHECK` 정의 반영:
  ```dockerfile
  HEALTHCHECK --interval=30s --timeout=10s --retries=3 --start-period=5s \
      CMD python -c "import os, requests; prefix = os.getenv('DEFAULT_PREFIX', ''); requests.get(f'http://localhost:5000{prefix}/api/status')"
  ```
- 요청 사양에 맞춘 Gunicorn 운영서버 시작 `CMD` 반영 (`main:app` 타겟):
  ```dockerfile
  CMD ["gunicorn", "--bind", "0.0.0.0:5000", "--workers", "2", "--log-level", "debug", "--access-logfile", "-", "--error-logfile", "-", "--capture-output", "main:app"]
  ```
